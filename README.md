# 学生信息管理系统 (Student Management System)

## 1. 项目简介

本项目是一个基于 Web 的纯学生端信息管理系统，主要服务于在校大学生。
彻底去除了传统的管理员臃肿后台，学生登录后即可完成日常的学习与事务办理。
核心功能包括：

- **个人档案**：查看基本信息、辅导员联系方式，并可修改个人手机号和邮箱。
- **在线选课**：可视化查看待选课程，系统自带【时间冲突检测】机制，防止课表打架。
- **我的课表**：以网格形式直观展示每周课程安排。
- **我的成绩**：查看平时成绩、期末成绩及总评成绩。
- **教学评价**：对已选课程进行 5 个维度的打分与评语提交。
- **请假与公告**：支持在线提交请假并撤回，查看校园最新公告。

## 2. 技术栈

- **后端**：Python 3.x + Flask 框架
- **前端**：HTML5 + Jinja2 模板引擎 + Bootstrap 5 (UI框架) + 原生 JavaScript
- **数据库**：MySQL 8.0
- **版本控制**：Git / GitHub

## 3. 环境配置说明

- Python 环境：>= 3.8
- 数据库：MySQL 8.0 (需提前安装并启动服务)

**1. 安装依赖库**
在终端中运行以下命令安装所需依赖：

```bash
pip install -r requirements.txt

*(如果没有 requirements.txt，至少需要执行 `pip install Flask PyMySQL`)*

**2. 数据库配置**

- 在 MySQL 中新建一个数据库（例如命名为 `student_manager`）。

- 导入项目根目录下的 `student_system.sql` 文件，系统会自动建表并插入演示数据。

- 打开 `app.py`，找到数据库连接的配置代码（通常在文件开头），修改为你自己的 MySQL 账号和密码。

## 4. 启动/运行方法

1. 确保已激活虚拟环境（如使用 PyCharm 自带环境）。

2. 在终端运行以下命令启动 Flask 服务：

bash

python app.py

3. 在浏览器中访问：`http://127.0.0.1:5000` （或控制台提示的端口号）。
